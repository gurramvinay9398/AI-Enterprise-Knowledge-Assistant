# Application Flow

## Main User Flow

Login
→ Dashboard
→ Ask Question
→ API
→ Authentication
→ Authorization
→ RAG Retrieval
→ LLM
→ Answer + Sources
→ Save Conversation
→ Frontend

## Document Flow

Upload
→ Validate
→ Store
→ Extract Text
→ Chunk
→ Embed
→ Vector Storage
→ Processed

## Conversation Flow

User Question
→ API
→ RAG
→ LLM
→ AI Answer
→ Save Messages
→ Display Response
