# Session 01 - Project Initiation and Requirement Analysis

## Duration
30 Minutes

## Objective
Understand the business problem before writing any code and prepare the initial project structure.

---

# Task 1 - Client Requirement Analysis

### Client Requirement

The client wants an AI application that allows employees to ask questions in simple English about company documents.

The system should understand documents such as:
- HR Policies
- SOPs
- Technical Manuals
- Training Documents
- Company Guidelines

Instead of manually searching through hundreds of documents, employees should receive accurate answers within seconds.

---

# Task 2 - Requirement Understanding

## What the system does

The application processes company documents, understands their content using AI, retrieves the relevant information, and generates simple answers with document references.

## Why the company needs it

- Saves employee time
- Improves business efficiency
- Provides quick access to company knowledge
- Reduces manual document searching
- Increases productivity

## Main Features

- Secure document upload
- AI-powered question answering
- Natural language search
- Answers with document references
- Fast information retrieval
- User authentication
- Admin dashboard

# Key Learning

Never start coding immediately.

A professional software project begins by understanding:
1. The client's problem.
2. The business objective.
3. The required features.
4. The initial project structure.

A clear understanding at the beginning reduces mistakes during development.
