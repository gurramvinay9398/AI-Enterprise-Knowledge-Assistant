# Session 04 – Objectives, Scope, and Stakeholders

## Duration

30 Minutes

## Objective

Understand the project goals, define the project boundaries, and identify everyone involved in the development and usage of the AI Enterprise Knowledge Assistant.

---

# Task 1 – Objectives

In this session, we defined the main objectives of the project.

The primary goal of the AI Enterprise Knowledge Assistant is to help employees quickly find accurate answers from enterprise documents using Artificial Intelligence.

### Main Objectives

* Generate accurate answers to employee queries.
* Provide simple and easy-to-understand responses.
* Reduce document search time.
* Improve employee productivity.
* Display document references with every answer.
* Provide a user-friendly interface.
* Build a secure and scalable application.

### Success Criteria

The project will be considered successful if employees regularly use the application, receive accurate answers, reduce manual document searching, and improve their daily productivity.

---

# Task 2 – Scope

We defined what will be included in Version 1 (MVP) of the project.

### Features Included

* User Login
* Secure Document Upload
* AI Question Answering
* Chat Interface
* Document References
* Admin Dashboard
* Conversation History
* Enterprise Document Management

### Future Enhancements

* Voice Assistant
* Multi-language Support
* Mobile Application
* Offline AI Models
* Integration with enterprise communication tools

Defining the scope helps avoid unnecessary features during development and keeps the project focused.

---

# Task 3 – Stakeholders

We identified the people involved in the project.

### Stakeholders

* Company Management
* Employees
* HR Team
* System Administrator
* Development Team
* Future Maintenance Team

Each stakeholder has different responsibilities and expectations. Understanding their roles helps us build a system that meets business and user needs.

---

# Key Learning

A successful software project requires more than coding. Before development begins, we must clearly define the project objectives, decide what features are included, and identify the stakeholders who will use, manage, and maintain the application. These sections help keep the project focused, reduce confusion, and ensure everyone has a common understanding of the product.

---

✅ Completed the **Objectives** section of the SRS.
